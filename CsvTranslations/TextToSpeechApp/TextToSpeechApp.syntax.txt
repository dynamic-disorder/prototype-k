TextToSpeechApp - reads translation CSV entries aloud with the Piper neural TTS engine

DESCRIPTION:
  Loads translation entries from a CSV file and reads them aloud in random order,
  alternating between the source and target languages to help with language learning.

USAGE:
  TextToSpeechApp [path] [line number] [--tts:{provider}]
  TextToSpeechApp /help  (or --help, -h)

ARGUMENTS:
  [path]               Optional path to a translation CSV file. Defaults to
                       translations.csv, searched for in the working directory and
                       its parents.
  [line number]        Optional 1-based line number to start reading from.

OPTIONS:
  --tts:{provider}     TTS provider (case-insensitive). Piper is the only provider;
                       any other value is reported and Piper is used instead.
                       Overrides TtsProvider in settings.json.
  -tts:{provider}      Shorthand for --tts:
  /help, --help, -h    Display this help information.

PROVIDERS:
  Piper                The only provider. A local neural engine (PiperSharp); the
                       engine and voice models are downloaded on first use. Runs on
                       Windows, Linux and macOS, playing through PowerShell's
                       SoundPlayer on Windows, afplay on macOS, and pw-play, paplay,
                       aplay or ffplay on Linux.

EXAMPLES:
  # Default CSV file
  TextToSpeechApp

  # A specific CSV file
  TextToSpeechApp "csv_files/finnish_english_corporate_phrases.csv"

  # Start from line 50
  TextToSpeechApp "csv_files/finnish_english_technical_vocabulary.csv" 50

  # Name the provider explicitly (redundant: Piper is the only one)
  TextToSpeechApp --tts:piper

RUNTIME CONTROLS:
  Shown before reciting and after every 10 entries; see TextToSpeechApp.runtime_commands.txt.

An invalid argument aborts before reciting starts: this help is shown and the error is
printed in red before the process exits with a non-zero code.

For more details, see TextToSpeechApp.README.md
