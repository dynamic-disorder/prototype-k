OllamaTranslatorApp - Translates CSV and text files using a local Ollama AI model

Usage:
  OllamaTranslatorApp <source_file> <target_file>
  OllamaTranslatorApp --folder <folder_path>

Arguments:
  <source_file>   Path to the input file to translate (CSV, TXT, MD, TEXT)
  <target_file>   Path where the translated file is written

Options:
  --help, -h      Show this help message
  --folder, -f    Translate all supported files inside the specified folder

Modes:
  <source_file> <target_file> and --folder are mutually exclusive; supply exactly one.

Example:
  OllamaTranslatorApp --help
  OllamaTranslatorApp --folder my_folder
  OllamaTranslatorApp input.csv output.csv

Invalid parameters (a missing source or target, a source file or folder that does not
exist, or both modes at once) abort before any translation starts and exit with a
non-zero code, instead of silently skipping the work.

For more details, see OllamaTranslatorApp.README.md
