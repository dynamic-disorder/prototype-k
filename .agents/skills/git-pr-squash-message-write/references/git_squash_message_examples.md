# Squash & Merge Message Examples

Examples for `git-pr-squash-message-write` (rules live in its SKILL.md). Title 50-72 characters.

```
ABC-1234 Add user search with fuzzy matching

- Enables finding users by partial name or email
- Reduces search time from ~2min to ~5sec
```

```
ABC-1234 Fix login timeout under load

- Adds connection pooling and retry logic
- Reduces login failures by ~95%
```

No ticket:
```
Update cache configuration

- Increases TTL from 5min to 15min
- Requires config deployment
```
